# Bootstrap CSS Breakpoint Indicator Browser Extension

Quickly and easily see the current CSS breakpoint of a website.

## Test pages

The [`tests`](tests/) folder has a test page for each supported Bootstrap version. Each page shows the breakpoint Bootstrap itself reports next to the extension's indicator, so you can resize the window and check that they match.

- [Bootstrap 4](https://coliff.github.io/bootstrap-css-breakpoint-indicator-extension/tests/bootstrap-4.html)
- [Bootstrap 5](https://coliff.github.io/bootstrap-css-breakpoint-indicator-extension/tests/bootstrap-5.html)
- [Bootstrap 6](https://coliff.github.io/bootstrap-css-breakpoint-indicator-extension/tests/bootstrap-6.html)

To run them locally, use `npm run serve`.
